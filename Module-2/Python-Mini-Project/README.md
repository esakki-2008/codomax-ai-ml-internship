# ExpenseTracker Pro 💰

A professional command-line expense management application built with Python for **Module 2 – Python Mini Project** of the Codomax Digital Solutions AI & ML Internship.

## Objective
ExpenseTracker Pro helps users record, review, and analyze daily expenses through a clean CLI.

## Features
- Add and validate expenses
- Categorize transactions
- Persistent CSV storage
- View expense history
- Total, average, and largest-expense analysis
- Category-wise spending report with percentages
- Automatic date/time recording
- Input validation and error handling
- Python standard library only

## Concepts Demonstrated
Variables, data types, functions, lists, dictionaries, conditions, loops, file handling, CSV processing, exception handling, datetime, and modular program structure.

## Run
python expense_tracker.py

No external packages are required.

## Data
The application stores transactions in expenses.csv with date, category, description, and amount.
